# 6월·9월 모의평가 추가

먼저 README.md 4절과 5절 ③을 읽고, practice-rebuild 스킬의 '준비'로 수능 자료도 함께 풀어 둔다.

## 준비
- 수능과 모의평가 압축 파일을 모두 풀고 `extract.py`로 자른다(수능은 practice-rebuild의 '준비'). 모의평가 압축 안의 폴더 이름이 깨져 있으면 EUC-KR로 읽는다(문제/정답/해설).
- 2026년 11월에 받은 9월 문제지는 1년씩 밀려 있었다. README 5절 ③의 짝 맞추기를 먼저 한다: 문제지 첫머리의 학년도, 그리고 문제 n번 글이 해설 n번 글과 가장 비슷한지.

## 자르기와 확인
- 회차마다 "문제 20/20 해설 20/20", 정답 일치를 확인한다. 정답표가 그림·한글(hwp)뿐이면 해설의 정답을 쓴다.
- extract.py는 이런 해설도 처리한다: "1. 답 ④" 모양, 글자가 깨진 한 단 해설(빈 줄 간격으로 나눔), 오른쪽 단 번호가 가운데보다 조금 왼쪽에 찍힌 문제지.

## 분류
1. `python3 src/practice/draft_mock.py <회차들>`: 초안을 codes_mock.json과 map.json에 넣는다(이미 있는 문항은 건드리지 않음).
2. check의 확신이 낮은(0.4 미만) 문항은 문제 글(info.json texts)을 읽고 주제를 정한다. 글이 깨졌으면 해설 글, 그래도 안 되면 그림 몇 장만 연다.
3. `python3 src/practice/draft_mock.py --fix 검토.json`({"p1_2027_06_02": "운동의 기술·그래프(직선)"} 또는 {id: [주제, 메모]})으로 반영한다. 주제는 codes_detail.json에 있는 71개 이름 중 하나.
4. classify.py → encrypt.js로 다시 만들고, 새 문항 분류표(CSV)를 선생님께 드린다(저장소에는 올리지 않음).
